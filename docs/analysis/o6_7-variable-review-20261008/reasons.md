# Reasons

Immergrün benötigt täglich vollständige Acker-/Kulturhistorie statt undatierter
Quoten. Die Einzelprüfung bindet 148 offene Variablen und 108 Originalfundstellen;
18 OPA-Beobachtungen zeigen Kalender-, Vollständigkeits-, NAPV-, Ereignis- und
Vertragslücken. Zwölf Fachentscheidungen bleiben in #140 offen, damit spätere
App-Implementierung keine Modellannahmen als bestätigte Förderregeln übernimmt.
