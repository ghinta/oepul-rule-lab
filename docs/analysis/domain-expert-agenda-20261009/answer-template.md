# Antwortvorlage für die Domainexperten

Eine Antwort kann mehrere bestehende Fragen gemeinsam klären. Bitte ausdrücklich
benennen, welche Klauseln und Maßnahmen sie umfasst und welche weiterhin offen
bleiben. Keine Antwort wird automatisch auf ähnlich benannte Variablen übertragen.

| Feld | Antwort |
| --- | --- |
| Entscheidungsfamilie und bestehende Frage-IDs | … |
| Maßnahme, konkrete Pflicht/Option, Entität und Wirkungsfläche | … |
| Fachliche Entscheidung und ausdrücklich verbleibende Restfrage | … |
| Quelle, genaue Fundstelle, Fassung, wirksames Jahr/Datum | … |
| Eingabebedeutung, Einheit, Zähler/Nenner, Zeitraum/Stichtag | … |
| Zulässiger Beleg und Umfang einer Vollständigkeitsbestätigung | … |
| Verhalten bei fehlender, bestätigter leerer, noch nicht fälliger und widersprüchlicher Angabe | … |
| Ausnahme, Rechtswirkung und betroffene Pflicht; erforderliche Anerkennung | … |
| Positive, negative und grenzwertige Sollfälle mit unabhängig begründetem Ergebnis | … |
| Fachlich verantwortliche Person, Datum und verbleibende Unsicherheit | … |

Dokumentierte Experten-/Betreiberwerte vor AMA, Auto im eigenen dokumentierten
Snapshot und sichtbare Herkunft neu angelegter Flächen sind bereits bestätigt.
Eine fachliche Antwort soll diese Eingabewege berücksichtigen; keine zusätzliche
amtliche Herkunftssperre einführen. Faktenerfassung, rechtliche Anerkennung,
indikative Prämie und tatsächliche Auszahlung getrennt beschreiben.

Luna-/Opus-Beispiele können einen Prüfbedarf zeigen. Das fachliche Soll kommt aus
der begründeten Expertenantwort und gültigen Quelle, nicht aus dem zu bewertenden
Modelloutput. Der Index und die Ursprungsfragen bleiben bis zur gesonderten,
nachvollziehbaren Aufnahmeprüfung offen.
