# Reasons

Die Domainexperten brauchen eine überschaubare Agenda statt verteilter Block- und
Einzelfragen. Zehn Familien bündeln gemeinsame Entscheidungen; 418 bestehende
Frage-IDs und acht offene o6_3-Blocker bleiben vollständig nachvollziehbar.

Gemeinsame Erfassung spart wiederholte Belegarbeit. Maßnahmenspezifische Mengen,
Zeiten, Rechtswirkungen und Prämien bleiben getrennt. Bestätigte Produktvorgaben
werden angewandt; keine Fachantwort oder Freigabe wird daraus erfunden.

Teilantworten ermöglichen kleine vollständige App-PRs mit kurzen reasons,
unabhängig begründetem fachlichem Soll und passenden Tests. Aktuelle Quellen und
technische Grundlagen können parallel vorbereitet werden. Die Agenda verändert
keine App-Regeln, Thesis, historischen Runs oder fachlichen Frageantworten.

Eine CI-Integritätsprüfung schützt vollständige IDs, offene Status, Quellhashes,
Entscheidungszuordnung und azyklische Umsetzungsabhängigkeiten. Beide bestehenden
Drafts bleiben offen; kein Merge im Konsolidierungsauftrag.
