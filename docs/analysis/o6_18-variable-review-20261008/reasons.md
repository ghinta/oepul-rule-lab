# Reason

Naturschutz braucht aktuelle behördliche Projektauflagen je tatsächlichem
Schlag. Vollständige Codekataloge allein erklären weder Vertragsaufnahme noch
Zahlbarkeit. Diese Einzelprüfung macht konkrete Zeit-, Tarif-, Doppelzählungs-
und Coveragefehler reproduzierbar, ohne historische Runs zu verändern.
Alle 16 fachlichen Entscheidungen bleiben zur gemeinsamen Klärung offen.
