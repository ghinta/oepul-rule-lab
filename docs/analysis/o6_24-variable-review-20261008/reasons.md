# Reason

WRRL hängt von einer aktuellen externen Rechts-/GIS-Fassung und tatsächlichen Schlag-/Dünge-/Buchereignissen ab. Dokumentierte Variablen- und Policyunterschiede verhindern eine ungeprüfte Übernahme der Runs; jede Aufnahmefrage bleibt im Sammelissue offen. Quellen, historische Läufe, Canonical Profile, App und Thesis unverändert.
