# Reason

Projektcodes und allgemeine Anerkennungsflags verlieren verbindliche Parameter,
Wirkungsfläche und Rechtszeitraum. Block 5 trennt Projekt, Verordnung,
individuelle Entscheidung und automatische Quellen-Ausnahme. Der positive
EBW-Basisstatus ohne Projektbeleg zeigt den Bedarf an konkreter Regelprüfung.
Bestehende offene Fragen, Experten-/Betreibervorrang und der eigene dokumentierte
Auto-Snapshot bleiben erhalten; keine neue Fachantwort wird angenommen.
