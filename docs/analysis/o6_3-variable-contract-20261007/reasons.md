# Why this input review exists

The Luna repair in #99 was not yet connected to the app. Each new input needs
source evidence, time scope, identity and a documented rule consumer. App #135
provides current facts, but not RGVE cohorts or measure-specific evidence.

The review maps all 46 typed input paths to 17 rule groups, 46 citations and
the app after #135. It distinguishes four reusable registered fields from
actual o6_3 consumption. Normative tables stay data, not editable farm fields.

Cohort identity, authoritative count basis, seasonal history and incident periods
need additional integration work. Open legal effects and shared funding rules
remain blockers. The Opus revisions still require a separate comparison.
Hash, schema, quote, coefficient and mapping checks reproduce ten visible
development observations. They do not approve funding or golden tests.
See Lab #97 and App #136.
