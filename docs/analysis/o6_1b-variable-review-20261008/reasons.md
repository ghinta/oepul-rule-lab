# Reasons

Das automatisierte 26-Maßnahmen-Inventar wurde zu weitgehend als abgeschlossene
Einzelprüfung dargestellt. BIO erhält deshalb einen eigenen nachvollziehbaren
Slice: alle Blattpfade, tatsächliche App-Projektion, wörtliche Originalbelege,
direkte Policy-Proben und konkrete offene Fachentscheidungen.

Die Arbeit erweitert den bestehenden Draft #103, um weitere offene PRs zu
vermeiden. Sie gibt keine Variable/Regel frei und verändert weder historische
Runs noch App, Quellen, Canonical Profile oder Thesis. Weitere Maßnahmen bleiben
ausstehend; fachliche Antworten werden im bestehenden Sammelissue #140 gesammelt.
