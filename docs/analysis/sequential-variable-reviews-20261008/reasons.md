# Reason

Die einzelnen Maßnahmenprüfungen benötigen eine gemeinsame Durchsicht, bevor
Variablen in die App gelangen. Eine nach Evidenzarten geordnete Liste macht
Wiederverwendung und unterschiedliche Scopes sichtbar, ohne offene Fachfragen
zu beantworten oder als erledigt zu markieren. Historische Beobachtungen
bleiben von unabhängig bestätigten Golden-Fällen getrennt.
